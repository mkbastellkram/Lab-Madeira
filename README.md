## Wichtig

Die Bilder sind bewusst **Bildslots**, keine Fake-Fotos. Echte PR-Bilder werden später mit Quelle/Lizenz/GEO-Plausibilität eingesetzt.

## GitHub Upload

Den Inhalt dieses Ordners direkt ins Repository hochladen:

- `index.html`
- `css`
- `js`
- `data`
- `assets`
- `gpx`
- `kml`
- `manifest.webmanifest`

Nicht den äußeren Ordner hochladen.

## GitHub Pages

Settings → Pages:

- Source: Deploy from a branch
- Branch: main
- Folder: /(root)
- Save

Danach 1–2 Minuten warten.
